# Autonomous Agricultural Grain Silo Aeration & Quality Optimization Hub

## Project Description

A web-based system for monitoring agricultural grain silos, tracking moisture and temperature, managing aeration fans, customers, vendors, sales, purchases, payments, budgets, and financial reports.

## Technologies Used

- HTML
- CSS
- JavaScript
- Spring Boot
- MySQL
- REST API

## Frontend Features

- Dashboard
- Silo Management
- Telemetry Monitoring
- Customer Management
- Vendor Management
- Sales & Invoices
- Purchase Orders & Vendor Bills
- Payments
- Financial Reports
- Budget Management
